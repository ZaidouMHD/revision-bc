🔴 SECTION A – Régimes Hebdomadaires & Généralités

A Repos Légal (RL)

Principe : Le repos légal est fixé le dimanche 0h-24h en régime hebdomadaire.

  • Jour de repos obligatoire
  • Compensation majorée (175% entre 6h-21h)
  • Peut être décalé par nécessités de service
📌 Sources :
• APORTT Fiche 6 - Régimes hebdomadaires

A Repos Compensateur (RC)

Définition : Jour de repos en semaine (lun-sam)

  • Fixé en régime hebdomadaire
  • Jour de repos ordinaire
  • Compensation standardisée (125% entre 6h-21h)
  • Peut être décalé par nécessités de service
  • Différent de RL (dimanche)

RC + RL = 2 jours repos hebdo minimum

📌 Sources :
• APORTT Fiche 6 - Régimes hebdomadaires (RC définition)
• Arrêté 5 septembre 2019 - Art. 49 (permanence RC)

A Journées de Travail Hebdomadaire

Structure standard : 5 jours de travail + 1 RL + 1 RC

  • Grande semaine : 6 jours travail + 2 jours repos
  • Petite semaine : 4 jours travail + 2 jours repos

Alternance de semaines pour équilibrer les heures annuelles.

📌 Sources :
• APORTT Fiche 6 - Structure hebdomadaire

A Interruption de Service (IS)

Régime avec IS : Journée divisée en 2 parties avec coupure méridienne

  • Matin + Après-midi
  • Coupure entre 11h30 et 14h30
  • Durée : 45 min à 2h
  • = Temps de repos (non rémunéré)
📌 Sources :
• APORTT Fiche 6 - Interruption de service

A Pause Obligatoire

Déclenchement : À partir de 6 heures ininterrompues de travail

  • Durée : 20 minutes
  • Moment : Par principe au milieu de la journée
  • Statut : Temps de travail (agent à disposition)
  • S'applique en régime cyclique ET hebdomadaire continu
📌 Sources :
• APORTT Fiche 6 - Pauses obligatoires

A Prise de Service Décalée (Cyclique)

Définition : Décalage en amont/aval de l'horaire habituel

Type de reposCompensation RPS
RC (Repos Comp.)0,25
RL ou JF0,60

Note : Non cumulable avec services supplémentaires

📌 Sources :
• APORTT Fiche 6-7 - Prise de service décalée

A Définition du Travailleur de Nuit

Critères cumulatifs :

  • OU Minimum 3 heures par nuit (21h-6h)
  • Au moins 2 fois par semaine
  • OU Minimum 270 heures nuit / année civile
📌 Sources :
• guide règles TT.pdf - Définition travailleur de nuit

A Durée Maximale Nuit (Travailleur)

Limite horaire : 8 heures maximum en moyenne par 24h

  • Période de calcul : 3 mois civils
  • Si dépassement : Chef de service impose congés avant fin trimestre
  • Selon planning concerté avec agent
📌 Sources :
• guide règles TT.pdf - Travail de nuit (durée maximale)

A Temps Partiel – Exclusions

Ne peuvent PAS demander le TP :

  • ❌ Policiers adjoints (sauf TP thérapeutique)
  • ❌ Cadets de la République
  • ✅ Tous les autres fonctionnaires titulaires
📌 Sources :
• guide règles TT.pdf - Temps partiel (exclusions)

A TP de Droit – Quotités

Quotités possibles : 50%, 60%, 70% ou 80%

  • Pour raisons familiales
  • Père, mère ou conjointement
  • Pour élever un enfant
📌 Sources :
• guide règles TT.pdf - Temps partiel de droit

A Dérogations – Missions Spécifiques

Cas concernés : Escortes, protection personnalités, forces mobiles...

  • Repos hebdo : 24h après 12 jours max (au lieu de 35h)
  • Repos journaliers : Restitution dans les 12 jours
  • Repos hebdo : Restitution dans les 21 jours
📌 Sources :
• APORTT art. 68-69 - Dérogations missions

🔵 SECTION B – Services Supplémentaires & Indemnités (RCSS)

B Qu'est-ce que RCSS ?

Acronyme : Repos Compensateur de Service Supplémentaire

  • Compensation temporelle (en heures/jours)
  • Générés par : permanence, astreinte, dépassements, rappels
  • À récupérer dans l'année civile de génération
📌 Sources :
• Arrêté 5 septembre 2019 - RCSS
• guide règles TT.pdf - RCSS (définition)

B Permanence sur RC (6h-21h)

Compensation : 125%

  • RC = Repos compensateur
  • Taux unique quelle que soit la période
  • Agent au service = temps de travail effectif
📌 Sources :
• APORTT Fiche 12 - Services supplémentaires (permanence)

B Permanence sur RL (6h-21h)

Compensation : 175%

  • RL = Repos légal (dimanche)
  • Majorée par rapport à RC
  • Agent requis au service
📌 Sources :
• APORTT Fiche 12 - Permanence RL

B Nuit Samedi→Dimanche (21h-6h)

Compensation : 200%

  • Taux maximal pour nuit
  • Cumul : fin de week-end + période nocturne
  • = Taux veille de JF
📌 Sources :
• Arrêté 5 sept. 2019 (Section 2.1 - Indemnités nuit sam-dim)

B Nuits Ordinaires Semaine (21h-6h)

Compensation : 150%

  • Lun, mar, mer, jeu, ven (nuits)
  • Taux intermédiaire
  • Exemple : nuit ven→sam = 150%
📌 Sources :
• Arrêté 5 sept. 2019 (Section 2.1 - Indemnités nuit semaine)

B Nuit Dimanche→Lundi (21h-6h)

Compensation : 150%

  • Dimanche = repos légal, pas nuit spécifique
  • Taux nuit ordinaire (départ après dim)
  • ≠ 200% (réservé sam→dim + veille JF)
📌 Sources :
• Arrêté 5 sept. 2019 (Section 2.1 - Indemnités nuit)

B Jour Férié (6h-21h)

Compensation : 175%

  • = Taux RL (repos légal)
  • JF travaillé entre jour et nuit
  • Majorée par nécessité publique
📌 Sources :
• Arrêté 5 sept. 2019 (Section 2.1 - Indemnités JF)

B Nuit Veille de JF (21h-6h)

Compensation : 200%

  • Équivalent sam→dim
  • Nuit + période pré-JF
  • Taux maximal période nocturne
📌 Sources :
• Arrêté 5 sept. 2019 (Section 2.1 - Indemnités nuit veille JF)

B Plafond Compte Actif RCSS

Maximum : 160 heures

  • Au-delà = basculage compte historique
  • Gestion prioritaire du compte actif
  • Débordement automatique après 160h
📌 Sources :
• guide règles TT.pdf - RCSS (plafond compte actif)

B Délai Récupération RCSS Actif

Délai : 30 jours

  • À partir de génération du RCSS
  • Récupération en repos ou indemnisation
  • Plan prévisionnel par chef de service
📌 Sources :
• guide règles TT.pdf - RCSS (délai récupération 30 jours)

B Compte Historique RCSS

Réception : RCSS au-delà de 160h du compte actif

  • Cumulable illimité
  • Peut être versé sur CET
  • Peut être indemnisé financièrement
  • Non comptabilisé temps de travail annuel
📌 Sources :
• guide règles TT.pdf - RCSS (compte historique)

B RCSS & CET

Compatibilité : OUI (compte historique)

  • RCSS historique → versé sur CET
  • OU indemnisation financière
  • Actif : récupération obligatoire en 30 jours
📌 Sources :
• guide règles TT.pdf - RCSS (CET et versement)

B Rappel & Compensation

Définition : Agent avisé APRÈS quitter le service

  • Compensation selon type de jour
  • Nuit/RL/JF/RC = taux majoré appliqué
  • Inclus trajet si domicile distant
📌 Sources :
• guide règles TT.pdf - Rappel (définition et compensation)

B RCSS & RPS : Exclusivité

Règle : EXCLUSIFS (non cumulables)

  • Une vacation = RPS OU RCSS
  • Jamais les deux simultanément
  • Service supplémentaire → RCSS prioritaire
📌 Sources :
• guide règles TT.pdf - RCSS/RPS (exclusivité)

B Congés Non Rappelables

Protection : Congés annuels, bonifiés, CET, ARTT accolés

  • Ne peuvent être interrompus
  • Agent en congé = indisponible
  • CLM = rappelable en urgence absolue
📌 Sources :
• guide règles TT.pdf - Congés non rappelables

B Plage Nocturne – Définition

Horaires : 21h à 6h

  • Identique pour permanence & astreinte
  • Tout travail dans ces horaires = majoré
  • Dépendance jour civil de fin
📌 Sources :
• guide règles TT.pdf - Plage nocturne (21h-6h)

🟡 SECTION C – Congés & Droits ARTT/CET

C Congé Annuel – Durée Légale

Durée : 30 jours / année civile

  • Minimum légal
  • Droit ouvert dès 1ère année
  • Prise par ordre calendaire
  • Plan prévisionnel obligatoire
📌 Sources :
• guide règles TT.pdf - Congés annuels

C Plafond CET – Maximum

Plafond maximal : 60 jours

  • Cumul de années successives
  • Dépôt entre 1er-31 janvier
  • Risque d'extinction au-delà
📌 Sources :
• guide règles TT.pdf - CET (plafond 60 jours)

C CET – Jours Indemnitables

Au-delà 15 jours : Indemnisables ou CET

  • 15 premiers jours : Repos obligatoire
  • Au-delà 15 jours : Indemnisation OU CET
  • Pas d'extinction au-delà 60j
📌 Sources :
• guide règles TT.pdf - CET (jours indemnitables)

C Congé Maternité (1er & 2e enfant)

Durée prénatale : 6 semaines

Durée postnatale : 10 semaines

Total : 16 semaines

📌 Sources :
• guide règles TT.pdf - Congé maternité (1-2e enfant)

C Congé Maternité (≥ 3e enfant)

Durée prénatale : 8 semaines

Durée postnatale : 18 semaines

Total : 26 semaines

📌 Sources :
• guide règles TT.pdf - Congé maternité (≥3e enfant)

C Congé Maternité (Jumeaux)

Durée totale : 34 semaines

  • Prénatale + postnatale
  • Dérogation à la limite standard
  • Rémunérée intégralement
📌 Sources :
• guide règles TT.pdf - Congé maternité (jumeaux)

C Congé Maternité (Triplés+)

Durée totale : 46 semaines

  • Maximum légal
  • Pour 3 enfants ou plus
  • Prestations identiques jumeaux
📌 Sources :
• guide règles TT.pdf - Congé maternité (triplés+)

C Report Congés Annuels

Condition : Avoir pris ≥ 20 jours en année N

  • Max 5 jours reportables
  • À prendre avant 31 mai année suivante
  • Motifs exceptionnels seulement
📌 Sources :
• guide règles TT.pdf - Congés annuels (report)

C ARTT – Réduction Temps Travail

Objectif : Ramener 1607h annuelles

  • Crédits selon régime et corps
  • Posables sur plan prévisionnel
  • Protégés si diffusés ≥ 10 jours
  • Affectés par journée solidarité
📌 Sources :
• guide règles TT.pdf - ARTT (Aménagement Réduction Temps Travail)

C Impact Absences sur ARTT

Sans impact : Congé maternité ✅

Avec impact : CMO, CLM, congé parental ❌

  • Réduction prorata des droits ARTT
  • Période d'absence décomptée
📌 Sources :
• guide règles TT.pdf - ARTT (impact absences)

🟢 SECTION D – Astreinte & Permanence

D Définition Permanence

Permanence : Agent requis d'être au service

  • Présent physiquement aux locaux
  • Disponibilité immédiate
  • = Temps de travail effectif
  • Rémunération majorée selon jour
📌 Sources :
• APORTT Fiche 11 - Définition permanence

D Astreinte vs Permanence

Astreinte : Agent à domicile disponible

  • Loin des locaux
  • Délai d'intervention : brefs délais
  • Sans intervention = pas TT effectif
  • ≠ Permanence
📌 Sources :
• APORTT Fiche 11 - Astreinte (définition et différences)

D Plage Nocturne Astreinte

Horaires : 21h à 6h

  • Identique permanence
  • Compensation majorée si intervention
  • Rémunération période sans intervention
📌 Sources :
• APORTT Fiche 11 - Plage nocturne astreinte

D Astreinte sans Intervention

Statut : PAS temps de travail

  • Rémunération forfaitaire
  • Agent à sa charge
  • OU compensation horaire si crédit insuffisant
📌 Sources :
• APORTT Fiche 11 - Astreinte sans intervention

D Rappel Astreinte – Télétravail Intervention

Trajet : NON dû en TLI

  • Travail à domicile = pas déplacement
  • Temps TLI = 100% rémunéré
  • Code GesTT : rappel + commentaire TLI
📌 Sources :
• guide règles TT.pdf - Rappel astreinte (TLI)

D Astreinte Régime Cyclique

Compatibilité : NON

  • Astreinte = régime hebdomadaire uniquement
  • Cycliques → permanence possible
  • Pas d'astreinte pour agents cycle
📌 Sources :
• APORTT Fiche 11 - Astreinte (régimes applicables)

🟣 SECTION E – RPS (Repos de Pénibilité Spécifique)

E Qu'est-ce que RPS ?

Acronyme : Repos de Pénibilité Spécifique

  • Compensation temporelle
  • Pour pénibilité des rythmes
  • Réduit durée annuelle 1607h
  • Différent de RCSS (services supplémentaires)
📌 Sources :
• guide règles TT.pdf - RPS (définition)

E Coefficient RPS : Nuit Semaine

Nuit (21h-6h, lun-sam) : Coefficient 0,1

  • S'applique à DMJ (cycliques)
  • À chaque heure nuit (hebdo)
  • Non cumulable avec dimanche
📌 Sources :
• guide règles TT.pdf - RPS (coefficient nuit 0,1)

E Coefficient RPS : Dimanche

Dimanche : Coefficient 0,4

  • Appliqué à DMJ (cyclique)
  • OU à chaque heure travaillée (hebdo)
  • Le plus élevé entre nuit & dimanche
📌 Sources :
• guide règles TT.pdf - RPS (coefficient dimanche 0,4)

E Coefficient RPS : Cumulabilité

Règle : NON cumulables

  • On retient le coefficient MAXIMUM
  • Exemple : dim nuit = 0,4 (>0,1)
  • Pas de cumul 0,25 + 0,1 = 0,25
📌 Sources :
• guide règles TT.pdf - RPS (non-cumulabilité coefficients)

E RPS & Services Supplémentaires

Compatibilité : EXCLUSIFS

  • Une vacation = RPS OU RCSS, jamais les deux
  • PAS de double compensation
  • Services supplémentaires → RCSS
  • Pénibilité usuelle → RPS
📌 Sources :
• guide règles TT.pdf - RPS/RCSS (exclusivité)

E Réduction Durée Annuelle par RPS

Impact : Réduction de 1607h annuelles

  • Crédits RPS retranchés annuellement
  • Posables sur plan prévisionnel
  • Protégés si ≥ 10j de diffusion
📌 Sources :
• guide règles TT.pdf - RPS (réduction durée annuelle)
